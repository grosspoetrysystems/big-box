# big-box

Agent skills from [Gross Poetry Systems](https://grosspoetry.systems). Each one stands alone; pick the ones you need.

| Skill | What it does | Install |
|---|---|---|
| [rack-mount-ts](skills/rack-mount-ts/) | Bootstrap production-ready TypeScript and Node.js repositories with a complete development substrate. | `npx skills add grosspoetrysystems/big-box --skill rack-mount-ts` |
| [rack-mount-go](skills/rack-mount-go/) | Bootstrap production-ready Go repositories with a complete development substrate. | `npx skills add grosspoetrysystems/big-box --skill rack-mount-go` |
| [cable-run-ts](skills/cable-run-ts/) | Wire the signal chain for AI-capable projects. Rack-mount sets up the physical gear — cable-run connects the inference layer. | `npx skills add grosspoetrysystems/big-box --skill cable-run-ts` |
| [cable-run-go](skills/cable-run-go/) | Wire the signal chain for AI-capable Go projects. Rack-mount-go sets up the project substrate — cable-run-go connects the inference layer. | `npx skills add grosspoetrysystems/big-box --skill cable-run-go` |

`npx skills add grosspoetrysystems/big-box` without `--skill` lets you choose from the list. `npx skills update` brings installed copies up to date.
